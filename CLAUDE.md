# The Mentorium — project rules

- Read the bundled Next.js docs in `node_modules/next/dist/docs/` before using an API you are unsure of. This is Next.js 16 with `cacheComponents` on: no `new Date()`/`Math.random()` in prerendered components without `"use cache"`.
- All site text and data live in `src/content/site.ts`. Pages read from there; do not hard-code content in components when it belongs in content.
- Never invent institutional details, people, credentials, testimonials, statistics, prices or contact details. Use `null`/empty lists and let the UI show a "coming soon" state.
- Never promise guaranteed employment. Assessments are guidance tools, not decisions or diagnoses.
- Brand: navy `#142B49`, gold `#C29A50` (shapes only — gold text uses `gold-700` on light, `gold-300` on navy), off-white `#F3F5F8`, teal `#315E60`. Tokens are in `src/app/globals.css`; see `docs/brand.md`.
- Logo files are generated by `scripts/brand/generate_logo.py`; change the script, not the SVGs.
- Work on a branch, keep `npm run build` and `npm run lint` passing, and merge to `main` only after the preview is approved.
