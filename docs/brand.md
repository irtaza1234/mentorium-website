# Mentorium brand guidelines

## Logo

The logo keeps the original concept: a shield (institution), a compass star (direction and guidance), the
wordmark **MENTORIUM** in a classical roman serif (Cinzel), and the tagline *Your Gateway to Career Excellence*
(Montserrat). The logo reads "MENTORIUM" only, with no "THE".

| File | Use |
| --- | --- |
| `mentorium-logo-primary.svg` | Main logo, on white or off-white |
| `mentorium-logo-reversed.svg` | On navy or dark photos |
| `mentorium-logo-horizontal-primary.svg` | Website header, letterheads |
| `mentorium-logo-horizontal-reversed.svg` | Website footer, dark banners |
| `mentorium-logo-mono-navy.svg` / `-mono-white.svg` | Single-colour print, embossing, watermarks |
| `mentorium-emblem-primary.svg` / `-reversed.svg` | Emblem only: social avatars, stamps |
| `mentorium-favicon.svg` | Simplified emblem for browser tabs |
| `mentorium-social-1200x630.png` | Link previews on social media |
| `mentorium-avatar-400.png` | Profile picture for social accounts |

Keep clear space around the logo of at least the height of the letter "M". Do not stretch, recolour outside
these versions, add effects, or place the primary logo on busy backgrounds.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Primary navy | `#142B49` | Headings, header, footer, primary surfaces |
| Prestige gold | `#C29A50` | Accents, icons, buttons, dividers — not for text on white |
| Deep gold | `#8C6A2B` | Gold-coloured text on light backgrounds (5.0 : 1 contrast) |
| Light gold | `#E3C98F` | Gold text on navy (8.9 : 1 contrast) |
| Off white | `#F3F5F8` | Section backgrounds |
| Teal green | `#315E60` | Verified badges, success states, secondary accents |
| Heritage burgundy | `#6B1A2A` | Sparing accent: certificates, print, error text |

## Typography

- Headings: Montserrat, semibold (600)
- Body: Inter, regular (400)
- Wordmark only: Cinzel (inside the logo files; not used for running text)

## Style

Clean, spacious and institutional. Real photographs of the institute's own people and sessions, not
generic stock. Subtle motion only (fade and rise on load); no parallax, auto-playing video or heavy gradients.
